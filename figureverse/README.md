# 模玩集市 FIGUREVERSE

一个专注手办模型的交易 + 社区 + 第三方鉴定担保平台的响应式网页演示（纯 HTML / CSS / JS，无外部依赖）。

## 运行方式

直接双击打开 `index.html` 即可，或在任意静态服务器下访问：

```bash
python -m http.server 8000 --directory .
```

然后访问 `http://localhost:8000`。

## 功能模块

- 发现市场：分类 / 品相 / 价格排序 / 已鉴定筛选，商品卡片带防伪鉴定徽章
- 商品详情与担保交易：买家付款 → 平台托管 → 卖家发货 → 确认收货放款，全程模拟
- 社区广场：晒图 / 讨论 / 开箱 / 求助，点赞、关注、评论入口
- 求购大厅：发布心愿单、出价报价
- 鉴定中心：标准 / 加急 / 视频直播三档服务，上传照片模拟出证，生成防伪证书
- 站内聊天：联系人列表、消息收发、自动回复模拟
- 我的订单 / 我的收藏：担保订单状态流转、收藏管理

## 目录结构

```text
index.html        页面骨架
css/style.css     设计系统与全部样式（暗色霓虹 + 玻璃拟态）
js/app.js         数据、视图渲染与全部交互
assets/figures/   真实手办照片（示例商品图）
```
